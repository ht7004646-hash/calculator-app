# 🧮 Smart Calculator

A modern and responsive Calculator built using HTML, CSS and Vanilla JavaScript.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear (AC)
- ⌫ Delete Last Character
- 🌙 Dark / Light Theme
- 📜 Calculation History
- 📱 Responsive Design
- ⚡ Fast Performance

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
